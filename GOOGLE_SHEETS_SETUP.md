# Підключення ELECTRO LAB до Google Sheets

## 1. Створення таблиці та вебзастосунку
1. Відкрий [Google Apps Script](https://script.google.com/) під своїм Google-акаунтом.
2. Створи новий проєкт, назви його **ELECTRO LAB — збір результатів**.
3. Заміни вміст файлу `Code.gs` кодом із цього репозиторію: [Code.gs](./Code.gs).
4. Натисни **Deploy → New deployment**.
5. Тип: **Web app**. Execute as: **Me**. Who has access: **Anyone**.
6. Натисни Deploy і надай запитані дозволи Google.
7. Скопіюй URL вебзастосунку, що закінчується на `/exec`.
8. Відкрий цей URL у браузері. У відповіді має бути `"ok":true` та посилання `spreadsheetUrl` на створену таблицю.

## 2. Підключення до сайту
У файлі `index.html` знайди рядок:

```js
const SHEETS_WEB_APP_URL = 'PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE';
```

Заміни текст-заповнювач на URL вебзастосунку Apps Script, збережи файл і опублікуй зміни на GitHub Pages.

## 3. Що потрапляє в таблицю
Окремий рядок на кожне завершення лабораторної: дата й час, учень, клас, оцінка, відповіді на контрольні питання, кількість спроб, результати порівнянь, параметри фінальної конструкції, бали за рівнями та повний JSON із даними роботи. Повторне надсилання тієї самої спроби не створює дубль.

**Примітка:** браузер надсилає дані через запит без CORS-доступу до відповіді. Після відправлення сайт показує, що запит надіслано; остаточне підтвердження — поява нового рядка у Google Sheets. URL вебзастосунку є публічним endpoint: не зберігай у таблиці зайві персональні дані й не публікуй саму таблицю для всіх.
